# 远程飞行与区域防御 · 教学沙盘

这是一个面向系统工程科普的交互式 3D 地球演示。它展示虚构远程飞行任务的阶段划分、导航状态估计与不确定性，以及类似末段区域防御系统的公开概念链路。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 交互

- 拖动地球旋转，滚轮缩放。
- 使用底部控制条播放、暂停、跳到下一阶段或拖动时间线。
- 左侧可切换轨迹、不确定性、防御范围与标签。
- 点击底部“原理与难点”查看系统工程说明。

## 安全与建模边界

- 坐标、轨迹、性能、交会条件和时序均为虚构或教学缩放。
- 飞行轨迹是视觉插值，不是弹道求解器。
- 导航数据是概念可视化，不实现真实制导、瞄准或目标定位。
- 防御链路用于解释公开的系统工程概念，不模拟现实装备能力。
- 不应用于任何现实武器设计、部署、瞄准或效能评估。
